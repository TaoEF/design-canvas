# Wiki Update Workflow

1. Read `.project-wiki/schema.md`.
2. Choose entity type.
3. Prefer updating an existing page before creating a new one.
4. Cite source-of-truth files.
5. Mark source status.
6. Record conflicts instead of smoothing them over.
7. Preserve unstructured input in `raw/` when the source is a transcript, rough
   note, audit, or research fragment that should not become authoritative yet.
8. Promote only durable claims into structured wiki pages.
9. Update `.project-wiki/index.md` and `.project-wiki/log.md`.
