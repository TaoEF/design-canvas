# HTML Design 试用：玩具简史

打开 `toy-history.html` 即可查看 8 页 1280 × 720 的演示。图片、样式、编辑器均内嵌，离线可用，无需安装依赖或启动服务。

- 纯单页居中：默认画布预览，保留 HTML 原有交互；左侧缩略图、页脚 ‹ › 换页，页脚右侧缩放。
- 点「编辑」进入编辑，点「✓ 完成」回到画布预览：拖动移动元素，文字角点等比缩放字号与行距，边点只调整文本框；方向键微调位置。
- 双击文字修改，上方提供格式工具条；双击图片替换。
- 顶部文字/图片图标添加内容，也可以拖入或粘贴图片。
- 空白处拖动框选，与元素相交即选中；Shift 或 Ctrl/⌘＋点击增减选择，Shift＋框选追加，Ctrl/⌘＋Shift＋方向键扩选。多选后可一起移动、微调、复制、删除和调整图层，批量操作一次撤销；Ctrl/⌘ A 保留原行为。
- Ctrl/⌘ Z 撤销，Ctrl/⌘ Shift Z 重做，Ctrl/⌘ D 复制元素，Delete 删除。
- 编辑时顶部「排版 / 画板」切换：把当前页的顶层可编辑元素转为绝对定位。切回「排版」会恢复切换前快照。
- 本地预览中停止操作约 0.8 秒后自动保存到原 HTML；Cmd/Ctrl+S 或「更多 → 立即保存」立即写回。其他窗口只读同步，点「编辑」即可交接权限并直接进入编辑。离线打开通过「导出 → 下载 HTML」保存。
- 「更多 → 源码」查看或修改 HTML；「导出」直接下载 PDF、可编辑 PPTX，或下载/复制 HTML，也保留浏览器打印入口。
- 页脚右侧缩放控制：可放大、缩小、恢复 100% 或适应窗口。Ctrl/⌘ +、−、0、1 对应这些操作，Ctrl/⌘ 加滚轮或触控板捏合也可缩放。
- Esc 逐级结束改字、取消选中、退出编辑；播放时退出并回到画布预览。
- 浏览器打印：每个画板一页，隐藏编辑器界面，可另存 PDF。

采用 v7 编辑器，页面显隐由编辑器管理。PDF/PPTX 直接下载需要从项目根目录运行 `npm start`，通过本地预览打开；PPTX 中的文字和图片可单独编辑。导出包含当前未保存的手动改动；本地自动保存以同一 HTML 文件为准。AI 修改时使用项目的协作流程。

- 编辑时左侧缩略图支持拖动排序，页面菜单支持新增、复制、重命名、删除、上下移动，支持撤销和自动保存。
- 图片工具条提供 Fit（等比完整显示）/ Cover（等比裁切铺满）。
- 「播放」下拉提供「滚动播放 / 全屏播放」；前者上下连续浏览，后者单页全屏。空格和方向键翻页，Esc 返回画布预览并保留当前页。

## 文件

- `toy-history.html`：交付文件，包含 `html-design/editor.js` 原文。
- `assets/*.jpg`：四幅静物插图的本地副本，已经嵌入 HTML，不影响单文件使用。
- `build_demo.py`：首次生成示例的构建源，运行 `python3 demos/build_demo.py` 可重新生成。**浏览器中修改并保存后，请直接局部编辑保存文件，重新构建会覆盖那些手工修改。**

## 图像生成记录

使用内置 imagegen 工具生成，再压缩为 JPEG 内嵌。均为叙事示意，并非历史实物照片。完整提示词保存在 `assets/generation-prompts.json`。提示词概要：

1. Cover：复古泰迪熊、木陀螺、牵引木马、原色积木、灰色掌机共同构成一组博物馆图录式静物。黄油黄色无缝背景，自然侧光，材质真实，无字无标志。
2. Bear：蜂蜜棕色复古马海毛泰迪熊，红陶色无缝背景，全身入镜，自然侧光，博物馆图录摄影，无字无标志。
3. Bricks：红黄蓝拼接积木组成拱形小塔与散落零件，奶油色背景，低角度三分之四视角，柔和阴影，无字无标志。
4. Digital：1989 年式灰色掌机与黄色蛋形电子宠物组成静物，粉蓝背景，单色像素屏幕，怀旧摄影，无字无标志。

历史来源在第 8 页，文字可编辑，链接可点击。年代的含义分别注明，没有把代表性节点写成整个玩具品类的起源。
