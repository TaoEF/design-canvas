# 编辑器操作参考

默认单页居中预览并适应窗口，左侧页面栏170px，页脚与缩略图可换页。预览保留内容原有交互；点「编辑」进入普通元素编辑，点「✓ 完成」回到预览。页面管理和 AI 审阅可直接从预览执行，后台安全交接写权限；AI 接管等待与修改阶段暂停写操作。

## 内容与页面

- 拖动移动元素，双击改字或裁切图片，替换图片使用工具条「替换」。文字角点同比缩放字号、内部小字和行距，边点只调整框；图片提供「适应」完整显示与「填充」裁切铺满。可用顶部入口插入文字/图片，也可拖入或粘贴图片。
- 顶部「自动排版 / 手动」只切换当前页；切回自动排版恢复该页快照，原绝对定位 CSS 不会自动变成 Flex。
- 文字「更多 → 文字适配」检测溢出，提供「高度随内容」与「缩小字号适配」（最小6px），均可单步撤销。
- 预览即可拖动缩略图排序、点「＋」新增，页面「⋯」可复制、重命名、删除、上下移动；缩略图支持 Ctrl/⌘ D、Delete、Alt + ↑/↓。拖动取消不提交排序。
- 翠绿色辅助线提示页面/元素边缘和中心吸附；Alt/Option 暂停吸附，Esc 取消拖动。蓝色选框和控制点表示选择。

选中元素可拖动选框外的旋转手柄；90°附近吸附，Shift为15°步进，Alt/Option自由旋转，Esc取消。单选可在工具条「旋转」输入页面绝对角度或重置0°；多选绕共同中心，显示本次增量。旋转后拖动和缩放仍使用实际局部尺寸，保留已有transform/均匀scale/origin。反射、skew、3D等不可靠几何暂禁用这些操作。

## 图片裁切

双击图片或点「裁切」，在框内拖动调整取景，缩放控件放大源图，边点/角点改变裁切窗口。图片始终覆盖窗口；缩小框保留原图尺寸，扩大到需要时才增加覆盖。Enter/完成确认，Esc/取消恢复进入前整个状态。每个有效手势或数值确认可单独撤销；会话内 Undo/Redo 使用局部历史，首次迁移撤销后仍可继续。进入并完成、边界夹住、拖回起点不会产生新结构或历史。

有效操作才把原图片变为 `span[data-crop-frame="1"][data-el] > img[data-crop-image]`。外框承担布局、变换、边框和圆角；原 img 节点保留 id/class/src/alt/链接，其原布局 CSS 值转到外框，内部 CSS 承担真实取景。保留百分比宽度、auto 自然高度与 Grid/Flex item 属性；不以固定 px 替代百分比。内部 `--crop-zoom`、`--crop-x/y` 驱动标准 scale/translate/object-position，保存与离线显示不依赖内容脚本，不另存 block JSON。修改已有稿时保持两层和稳定 data-el，不把内部完整图片当成第二个设计对象。

完成前不自动保存裁切预览；保存、源码、导出、切页/选择、结束编辑和 AI 交接安全结束会话，取消不落盘。未确认会话的草稿备份使用进入前结构。适应/填充显式重置框内取景；Fit重入后的有效操作切换覆盖模式，无操作/夹住/回起点仍保留Fit。替换仅在新图解码成功后改源并重置居中覆盖；失败保留原图。普通元素缩放、复制、图层和删除仍以外框为一个对象。

安全转换需要 CSS Typed OM 和 content-box overflow clip；picture、滤镜/mask/clip-path、不支持的变换、auto 宽度且左右拉伸的绝对布局或结构选择器引起的布局变化会拒绝转换并保留原稿。首次转换用同步可逆布局探针验证当前 marked 对象；不保证后续媒体查询或外部类规则能重新控制已迁移外框。PPTX 原生保留源图裁切、旋转和常规统一圆角，复杂 CSS 圆角沿既有导出限制明确简化，非方50%圆角使用真正ellipse。手写contain缩放/偏心、隐藏内图或破坏clip/取景关系的CSS会被PPTX明确拒绝，QA不能因此报告可靠通过；PDF保留真实DOM。

## 选择、撤销与视图

- 空白处拖动框选，相交即选中；Shift 或 Ctrl/⌘ 点击增减选择，Shift 框选追加，Ctrl/⌘ Shift 方向键按方向扩选。多选支持移动、微调、旋转、复制、删除和图层调整，批量操作可一次撤销；Ctrl/⌘ A 保留浏览器/文字编辑行为。
- Ctrl/⌘ Z 撤销，Ctrl/⌘ Shift Z 重做，Ctrl/⌘ D 复制，Delete 删除。AI「放弃」是受保护的审阅恢复，成功刷新后清空此前普通撤销历史，不能用普通重做跨越恢复。
- Ctrl/⌘ + − 0 1 或 Ctrl/⌘ 加滚轮缩放；编辑时空格加拖动平移，「适应」回到居中。
- 「播放」下拉提供连续滚动和单页全屏播放。方向键、PageUp/PageDown、空格翻页，Esc 返回预览并保留当前页；受限浏览器可能改用当前窗口播放。

## 保存、审阅与导出

本地服务中停操作约0.8秒自动保存，Ctrl/⌘ S 或「更多 → 立即保存」立即保存；等顶部「已保存」再关闭。点击保存状态可重试或恢复草稿。离线通过「导出 → 下载 HTML」保存。

AI commit 后，悬停/聚焦「放弃」查看 before，点击才撤回；「接受」只更新审阅记录。多页右下可展开逐页处理或「全部接受」。人工修改并保存会接受相关范围，详见 [协作与审阅](collaboration.md)。

「更多 → 源码」查看/修改 HTML。「导出」提供 HTML、PDF 和可编辑 PPTX，后两者需 [本地运行环境](runtime.md)，导出点击时当前 DOM 的全部画板。PPTX 保留作者显式换行，普通段落随框宽重新排版；复杂 CSS 可能简化。离线仍可使用浏览器打印。
