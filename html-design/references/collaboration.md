# 同一文件协作流程

通过本地服务打开的 v6 及更新版本文件会自动保存到原路径。只有持有编辑权限的窗口可保存。AI 修改已有文件时，使用以下流程，不能用旧磁盘内容或生成器覆盖正在编辑的文件。

在项目根目录执行：

```sh
node html-design/collaborate.mjs begin demos/toy-history.html
```

命令等待浏览器结束当前拖动/改字、保存并暂停编辑，然后返回 JSON：`session`、`workFile`、`revision`、`expires`。只读并局部修改返回的 **workFile**，保留元素属性、图片和用户内联样式。先完成构建、研究等独立工作，再申请接管；权限有效期为 10 分钟。

修改完成后提交：

```sh
node html-design/collaborate.mjs commit <返回的 session.json 绝对路径>
```

提交检查接管权限和原文件版本，原子替换原路径。页面会同步最新文件，保留当前页和缩放。放弃修改用同一 session 执行 `cancel`。失败或超时不要直接覆盖原文件：工作副本仍保留，重新 `begin` 读取最新版本，再重新应用需要的局部修改。不要重试写入旧的整份 HTML。

如果浏览器的“源码”有尚未应用的修改，交接会等待用户应用或关闭；保存失败时不会确认交接。旧版编辑器没有交接能力，升级前要先提取其当前 DOM/最新下载文件，再替换脚本。

服务默认 `http://127.0.0.1:8876`；其他端口通过 `HTML_DESIGN_ORIGIN` 指定。不要让不同服务同时写同一项目。文件修改完成后必须结束接管，不要让它一直等待过期。

## 恢复与边界

- 每个文件在 `.html-design/history/` 内保留最近 10 个保存前版本。它们用于恢复，不是日常编辑入口。
- 保存前的待写快照备份在浏览器 IndexedDB；保存失败保留当前 DOM，显示重试。重新打开可使用“恢复草稿”。旧版本草稿只能下载，不自动覆盖新文件。
- 不同查询参数、根路径别名和项目内指向同一文件的符号链接都使用同一编辑锁。
- 普通文件编辑器、旧版脚本及绕过此流程的直接磁盘写入无法被浏览器阻止。服务通过版本校验阻止后续自动保存覆盖它们，但不自动合并冲突。
- 只有看到“已保存”（旧版为“已自动保存”）才表示已写入磁盘。浏览器突然退出前、尚在 800ms 等待期内的输入不保证已持久化。
