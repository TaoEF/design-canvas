# 同一文件协作流程

通过本地服务打开的 v6 及更新版本文件会自动保存到原路径。只有持有编辑权限的窗口可保存。AI 修改已有文件时，使用以下流程，不能用旧磁盘内容或生成器覆盖正在编辑的文件。

在项目根目录执行：

```sh
node html-design/collaborate.mjs begin demos/toy-history.html
```

命令等待浏览器结束当前拖动/改字、保存并暂停编辑，然后返回 JSON：`session`、`workFile`、`revision`、`expires`。只读并局部修改返回的 **workFile**，保留元素属性、图片和用户内联样式。先完成构建、研究等独立工作，再申请接管；权限有效期为 10 分钟。

修改完成后提交：

```sh
node html-design/collaborate.mjs commit <返回的 session.json 绝对路径>
```

提交检查接管权限和原文件版本，原子替换原路径。页面会同步最新文件，保留当前页和缩放。放弃修改用同一 session 执行 `cancel`。失败或超时不要直接覆盖原文件：工作副本仍保留，重新 `begin` 读取最新版本，再重新应用需要的局部修改。不要重试写入旧的整份 HTML。

如果浏览器的“源码”有尚未应用的修改，交接会等待用户应用或关闭；保存失败时不会确认交接。旧版编辑器没有交接能力，升级前要先提取其当前 DOM/最新下载文件，再替换脚本。

服务默认 `http://127.0.0.1:8876`；其他端口通过 `HTML_DESIGN_ORIGIN` 指定。不要让不同服务同时写同一项目。文件修改完成后必须结束接管，不要让它一直等待过期。

## 恢复与边界

- 每个文件在 `.html-design/history/` 内保留最近 10 个保存前版本。它们用于恢复，不是日常编辑入口。
- 保存前的待写快照备份在浏览器 IndexedDB；保存失败保留当前 DOM，显示重试。重新打开可使用“恢复草稿”。旧版本草稿只能下载，不自动覆盖新文件。
- 不同查询参数、根路径别名和项目内指向同一文件的符号链接都使用同一编辑锁。
- 普通文件编辑器、旧版脚本及绕过此流程的直接磁盘写入无法被浏览器阻止。服务通过版本校验阻止后续自动保存覆盖它们，但不自动合并冲突。
- 只有看到“已保存”（旧版为“已自动保存”）才表示已写入磁盘。浏览器突然退出前、尚在 800ms 等待期内的输入不保证已持久化。

## AI 修改的接受与撤回

AI commit 后，最新编辑器显示「AI 修改」。页内改动可逐页 Accept / Undo，新增页可撤回新增，删除页可查看旧版并恢复。共享 CSS/字体/link、内容脚本、全局属性/页外结构、已有页的重排，以及无法安全定位的页结构，均使用整份文档范围，避免恢复不完整。页面由 HTML parser 和稳定 data-artboard 标识识别，不是另一套 blocks 模型。

同页连续 AI 修改保留首次未接受基线。逐页接受只更新恢复参考，不重写 HTML；部分接受后再发生文档级修改，整份撤回仍保留已接受的页。人工编辑并保存会接受被修改页的 AI 结果；如果存在文档级待审阅，则人工修改接受整个审阅。保存反馈会说明隐式接受。选择/进入编辑/缩放、data-bbox 和序号变化不属于真实设计修改。

浏览器先结束手势/改字并 flush，再检查 revision、review generation、写租约和交接状态。flush 可能已经接受目标，所以列表变化时必须重新选择；服务不接受浏览器提供任意旧 HTML 来恢复。Undo 成功刷新文档，清空旧 DOM 的普通撤销/重做命令，之后人工编辑仍可形成新历史。owner 在预览态也可操作，viewer 只读。

### 持久基线和事务恢复

`.html-design/reviews/<规范路径哈希>/state.json` 以 0600 保存聚合 baseline 与审阅元数据，独立于 history 轮转。没有长期 after 副本：磁盘 HTML 仍是真值，部分接受只把接受的范围应用到恢复参考。清空审阅后 baseline 置空，保留 generation 与最近幂等请求收据。

涉及 HTML 的写入先原子落盘 prepared envelope（旧 state、fromRevision、toRevision、next state），再原子替换并同步 HTML 所在目录，最后原子 finalize state。每次读取/服务重启遇到 prepared 时，以实际 HTML 哈希选择：等于 to 完成 next；等于 from 回到旧 state；都不同则保留 journal 和基线、报告冲突并拒绝写入/撤回。存储失败会报错，不声称无待审阅。显式请求标识与最近完成的 AI token 支持丢响应后的相同请求重试；新版本后的旧请求不能覆盖。

审阅摘要只包含 scope、变更列表、原因、generation 和冲突标志；before HTML 按需单独获取。before 在独立 sandbox iframe 中呈现，只允许同源资源，不允许脚本、表单或上层导航，另清除脚本/事件/导航元素并使用 CSP；它不进入正式 stage、保存、普通历史或导出。保留原文档资源基址。离线下载不携带服务端基线，不提供服务审阅。

恢复保留当前编辑器 bundle 与不递减的 page/element 序号。不能协调多个服务进程，也不自动合并外部编辑；外部冲突需要保留副本与恢复记录后排查，不能删除审阅文件并假装完成撤回。
