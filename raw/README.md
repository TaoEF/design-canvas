# Raw Source Intake

Use this folder for unstructured material that may later be promoted into
`.project-wiki/`.

Raw material can include transcripts, rough notes, audits, research fragments,
URLs, screenshot descriptions, and migration source material.

Each raw file should include:

- source name or URL
- capture date
- access status
- processing status
- original or lightly normalized content

Raw files are evidence, not authority. Promote only durable claims into
structured wiki entities with source status and confidence.
