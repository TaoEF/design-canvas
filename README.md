# HTML Design

可编辑的单文件 HTML 画板，支持本地自动保存、AI 协作和 PDF / 可编辑 PPTX 导出。

## 启动

需要 Node.js 20 或更新版本。在项目根目录运行：

```sh
npm install
npm start
```

打开 `http://127.0.0.1:8876/demos/toy-history.html`。macOS 上自动使用已安装的 Google Chrome；其他环境先运行 `npx playwright install chromium`，或通过 `HTML_DESIGN_CHROME` 指定浏览器可执行文件。

## 编辑与播放

v7 提供纯单页居中画布，默认处于画布预览并适应窗口，保留 HTML 原有交互；点「编辑」才进入编辑，点「✓ 完成」回到画布预览。预览态即可拖动左侧缩略图排序，通过「＋」或页面菜单新增、复制、重命名和删除；页面操作后台自动交接写权限，支持撤销和自动保存，不会进入普通编辑模式。AI 接管等待和修改阶段暂停页面写操作。页脚放置翻页、页面标题和缩放控制。

编辑时顶部可切换「自动排版 / 手动」：画板只转换当前页，其他页保持原布局；切回排版恢复该页快照。选中文字时出现简洁格式工具条；拖动四角会同比缩放字号、内部小字、行距和字距，边点只调整文本框。选中图片时可替换，或在 适应（完整显示）与填充（裁切铺满）间切换。

编辑时可在空白处拖动框选，与元素相交即选中；Shift 或 Ctrl/⌘＋点击增减选择，Shift＋框选追加，Ctrl/⌘＋Shift＋方向键按方向扩选。多选支持一起移动、微调、复制、删除和置顶/置底，批量操作可一次撤销；Ctrl/⌘ A 保留原有行为。

拖动时会自动吸附到页面、同页其他元素的边缘和中心，翠绿色辅助线提示对齐；按住 Alt/Option 可暂停吸附，Esc 取消本次拖动。选框和控制点为明亮蓝色，深色背景下也清晰可见。辅助线不会写进保存或导出的文件。

「播放」下拉提供「滚动播放」和「全屏播放」：前者连续上下滚动，后者单页全屏。播放时方向键 / PageUp / PageDown / 空格换页，Esc 返回画布预览并保留当前页。全屏能力由浏览器提供；受限环境会提示并使用当前窗口播放。画布缩放用 Ctrl/⌘ + − 0 1；编辑时空格加拖动平移。

左侧页面栏170px，第一项缩略图保留顶部留边。顶部白色工具栏与黑色元素工具条区分；文字对齐图标单击循环切换，文字适配收纳在元素更多菜单，颜色入口为当前色圆点。界面以黑白灰为主，选框与辅助线使用蓝色、翠绿色区分；图标使用内嵌 Lucide SVG，离线不请求图标 CDN。图标许可附在构建产物内，见 [Lucide 许可](https://lucide.dev/license)。

## 自动保存与同一文件协作

在本地预览中，停止操作约 0.8 秒后自动写回当前 HTML；Ctrl/⌘ S 或“更多 → 立即保存”可立即保存。顶部显示“尚未保存 / 正在保存 / 已保存”，点击保存状态查看重试与草稿恢复。同一时间只有一个窗口持有写权限，其他窗口同步预览；点击“编辑”会等待当前窗口保存后交接，并进入普通编辑状态。审阅和页面管理可在预览中直接执行，按相同协议在后台交接。不同查询参数仍对应同一文件。

AI 修改前通过 `node html-design/collaborate.mjs begin demos/toy-history.html` 获取最新工作副本，修改该副本后 `commit <session.json>`，取消用 `cancel <session.json>`。浏览器在交接期间暂停编辑，提交后加载最新内容。完整流程见 [协作说明](html-design/references/collaboration.md)。

写入采用版本检查和原子替换；冲突时保留当前修改，不能用旧版本覆盖。连接失败会显示重试，并在浏览器保留草稿。`.html-design/history/` 为每个文件保留最近 10 个保存前版本。请等到“已保存”后关闭窗口；直接离线打开时仍以下载 HTML 保存。

## AI 修改审阅

AI 成功提交后，当前待审阅页底部自动出现「放弃｜接受」。悬停或键盘聚焦「放弃」可在原画布位置查看隔离、只读的修改前效果，离开、聚焦接受或按 Escape 返回修改后；点击放弃才执行受版本保护的 Undo，点击接受只更新审阅记录、不改写设计文件。按钮保持固定屏幕尺寸，缩放、平移或页面出界时仍夹紧在可见画布内。

多页待审阅时，右下显示默认收起的汇总和「全部接受」，展开后可逐项定位、放弃、接受。左侧显示真实页码、页面名与独立状态小标签；删除页标示基线中的原页码。唯一删除页仍保留恢复入口；唯一待审阅页不在当前页时保留导航提示。共享 CSS、内容脚本、全局结构或已有页面顺序变化明确使用「整份文档」范围，不能伪装为逐页恢复。页内 style / stylesheet link 同样属于全局；普通 style 属性仍可逐页处理。审阅写入期间暂停普通编辑，意外新内容会保留页面与草稿并提示冲突。
同页连续 AI 修改保留首次未接受的基线；部分接受后，后续整份文档撤回也会保留已经接受的成果。人工修改并保存某页会接受该页的 AI 改动，其他页仍可审阅；文档级审阅后的人工修改会接受整次审阅。仅选择、缩放或测量不会接受。正在输入时点撤回会先保存人工内容，刷新列表后需要重新选择，防止覆盖人的新工作。

基线独立保存在私有 `.html-design/reviews/`，不受最近 10 份历史轮转影响；刷新和服务重启后继续审阅。此能力依赖本地服务，下载的 HTML 不包含私有基线，离线仍可普通编辑、撤销和下载。所有窗口都可直接点击处理审阅；后台先等待原窗口保存并安全交接，版本或目标变化时停止旧动作，AI 修改或真实冲突时暂停操作；绕过服务直接改盘会保留基线并阻止盲目恢复。

审阅保存 HTML/CSS 声明与资源引用，不保存被原地覆盖的外部图片、字体或 CSS 文件；同一 URL 的资源字节变化不在此次撤回范围内。

从当前构建创建一份全新的两页试用稿（已有文件会拒绝覆盖）：

```sh
node html-design/review-demo.mjs
```

命令返回新路径，包含两项待审阅 AI 修改，可通过本地服务打开。后续修改仍使用 `collaborate.mjs begin/commit`。已有人工稿不会随构建升级；需要按协作流程更新内嵌编辑器后才显示此入口。实现与故障恢复边界见 [AI 审阅契约](.project-wiki/contracts/ai-review.md)。

## 导出

在顶部「导出」菜单选择：

- **下载 PDF**：每个画板一页，保持原始尺寸、背景和布局，文字可选择。
- **下载 PPTX（可编辑）**：文字转为原生文本框，图片为独立图片对象，基础背景和边框为原生形状。保留显式换行、段落、位置、字号和基本文字格式；普通段落随文本框宽度自动换行，可在 PowerPoint / WPS 中拉宽或收窄后重新排版。
- **浏览器打印 / PDF**：保留原有系统打印入口，离线打开 HTML 时也可使用。

导出使用点击按钮时的当前页面快照，包含未保存的手动编辑；不从磁盘重新读取旧 HTML。单页模式仍会导出全部画板，画布缩放和编辑器界面不会进入文件。失败会显示原因，不下载不完整文件。

PPTX 的页面必须具有相同宽高比。复杂 CSS 背景、滤镜、文字排版和圆角效果可能简化；字体在其他电脑上需要有对应字体。SVG 和 canvas 转为独立图片对象，普通文字和 `<img>` 不会整页合并为截图。

HTML 本身仍然自包含，可离线查看、编辑和下载 HTML。直接下载 PDF/PPTX 需要上述本地服务，不依赖外部转换网站。

## 文字测量与适配

将 `@chenglou/pretext@1.0.0` 内嵌到编辑器中，提供文字测量和适配。启动本地服务后打开 `/demos/flex-text-layout.html`，点击「编辑」，选中文字，再点元素工具条「更多 → 文字适配」。面板报告所需高度、当前高度和溢出状态；「高度随内容」保留字号并调整文本框，「缩小字号适配」保留文本框、按原比例缩小文字（最小字号 6px）。两项操作都支持一次撤销。

常用纯文本用 Pretext 预测并经过浏览器实际布局校验；混合字号、特殊词间距或预测不符时回退到浏览器测量。复杂块布局、生成内容、多栏和竖排等暂不支持自动适配。保持原有 contenteditable 和 HTML 结构，不持久化分行、测量缓存或诊断 UI；字体未就绪会提示重试，异步期间编辑状态变化会取消应用。

每次测量仍进行 DOM 校验，尚不声称有性能提升。不会自动缩小文字，不改变 PDF/PPTX 的浏览器布局真值。Pretext 使用 MIT 许可，许可与代码均内嵌，离线 HTML 无需额外加载资源。已有手动演示稿不会随构建更新。独立 Flex 示例中，保持「排版」模式并拖动左栏右侧中点，右栏会收窄、让位和重新折行；原 CSS 使用绝对定位的页面不会因此自动变成 Flex。

AI 可按需运行 `node html-design/text.mjs measure request.json` 比较多个候选宽度，或 `node html-design/text.mjs check design.html` 检查生成文件的文字溢出。只读命令复用本机浏览器，返回 JSON，不运行内容脚本、不写回 HTML，也不需要新的外部接口或密钥。读取的是保存快照，已有人工稿仍需先协作交接取得最新工作副本。字体/相对资源和完整参数见 [文字测量说明](html-design/references/text-measurement.md)。

## 开发与测试

编辑器源码按职责拆分在 `html-design/src/`：`editor.js` 负责编辑交互，`ui.js` / `editor.css` 提供界面，`pages.js` 管理缩略图和页面操作，`viewport.js` 管理居中/缩放/播放，`typography.js` 处理文字缩放，`guides.js` 处理对齐吸附和辅助线，`layers.js` 处理跨容器的叠放层级，`selection.js` 处理多选、框选和方向扩选，`icons.js` 封装图标，`identifiers.js` 管理复制时的引用，`persistence.js` / `drafts.js` 处理保存和草稿，`export.js` 处理导出。服务端的保存协议、导出和 PPTX 映射也分别独立。

```sh
npm run build  # 生成可直接嵌入 HTML 的单个 html-design/editor.js
npm test
```

修改源码后应整体替换 HTML 中的内嵌脚本；已有文档使用上述协作流程升级。构建不会自动覆盖演示稿，避免重建丢失手动修改。

测试涵盖画布几何、缩放下的辅助线吸附/取消/导出清理、页面管理和撤销、嵌套文字缩放、Fit/Cover、播放、键盘操作，以及自动保存、独占编辑、AI 交接、版本冲突、草稿恢复和 PDF/PPTX 导出回归。

不要同时启动多个服务写同一目录。普通文件编辑器或旧版页面绕过协作协议的修改不能被阻止；服务会检测文件版本变化，阻止旧页面自动覆盖，冲突需保留副本后处理。
